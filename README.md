# 🎮 Coin Collector Game

A Unity 3D game where the player explores a map and collects coins scattered throughout the environment.

## 🎯 Game Objective

The main objective is to explore the map, find and collect as many coins as possible.

## 🕹️ Gameplay

* Explore the game map
* Collect coins scattered around the environment
* Move around and navigate through the level
* Try to collect all available coins

## 🛠️ Technologies

* Unity
* C#
* Unity 3D

## 📸 Project

This project was developed as a game development project to practice Unity, C# scripting, player movement, environment design, and game mechanics.
